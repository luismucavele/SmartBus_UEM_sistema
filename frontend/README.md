# Frontend — SmartBus UEM

Aplicação React/Vite do SmartBus UEM.

- `src/pages/`: páginas e áreas funcionais do sistema.
- `src/components/`: componentes reutilizáveis, incluindo o mapa Leaflet.
- `src/data/`: dados demonstrativos temporários.
- `src/index.css`: identidade visual e responsividade.
- `public/`: ficheiros públicos, incluindo o manifesto de rotas.

O frontend deverá consumir a API REST do backend e não deverá ligar-se directamente ao MySQL.
